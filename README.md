# Overview

The <b>Student Management App</b> is a powerful tool designed to streamline the management of student records through an intuitive graphical interface. <br>
This project aims to provide a comprehensive solution for efficiently handling student data.

### Why Student-Managment-App?

This project simplifies the complexities of student record management. The core features include: <br>

- 🎨 User-friendly Interface: Simplifies interaction with student records, making it accessible for all users. <br>
- 📊 CRUD Operations: Easily add, edit, search, and delete student information with minimal effort. <br>
- 🗄️ MySQL Database Integration: Provides scalable and efficient data storage for multi-user and large-scale applications. <br>
- 🖥️ Structured Layout: Features menus and toolbars that enhance navigation and user experience. <br>
- 📈 Status Bar Visibility: Provides real-time feedback and information for better data management. <br>

# Getting Started

## Prerequisites

This project requires:

- 🐍 Python
- 📦 Conda package manager

## Installation

Build Student-Managment-App from the source and intsall dependencies:

1. <b>Clone the repository:</b>

`git clone https://github.com/HermanGavrylov/Student-Managment-App`

2. <b> Navigate to the project directory: </b>

`cd Student-Managment-App`

3. <b> Install the dependencies: </b>

<b> Using conda: </b>

`conda env create -f conda.yml`

## Usage

Run the project with:

<b> Using conda: </b>

`conda activate student-mgmt-env <br>
python main.py`

## Testing

Student-managment-app uses the <b>pytest</b> test framework. Run the test suite with:

<b>Using conda:</b>

`conda activate student-mgmt-env
pytest`
